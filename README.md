# Конвертер Flowseal → nfqws2-keenetic / OpenWrt

## Скачать готовую программу

Откройте [последний выпуск](../../releases/latest),
скачайте `ZapretKeeneticConverter-...-windows-x64.zip`, распакуйте архив и запустите
`ZapretKeeneticConverter.exe`. Python и установка пакета через `pip` для этой сборки не нужны.

Контрольная сумма каждого файла находится рядом в `SHA256SUMS.txt`. Подробности,
включая предупреждение Windows SmartScreen: [docs/DOWNLOAD_RU.md](docs/DOWNLOAD_RU.md).

> Для запуска после распаковки откройте `ZapretKeeneticConverter.exe` и следуйте [инструкции графического мастера](docs/GUI_RU.md). Полная подготовка роутера описана в [руководстве пользователя](docs/USER_GUIDE_RU.md), а установка через `nfqws-keenetic-web` — в [инструкции по веб-интерфейсу](docs/WEB_INTERFACE_RU.md).

Утилита переводит `.bat`-профили из
[`Flowseal/zapret-discord-youtube`](https://github.com/Flowseal/zapret-discord-youtube)
в штатный конфиг пакета
[`nfqws/nfqws2-keenetic`](https://github.com/nfqws/nfqws2-keenetic).

Это не текстовая замена параметров. Конвертер:

- разбирает независимые профили `winws`, разделённые `--new`;
- переводит стратегии zapret v1 `--dpi-desync` в zapret2 `--lua-desync`;
- разделяет HTTP, TLS, QUIC, Discord, STUN и unknown payload;
- сохраняет несколько fake-блобов и модификации TLS;
- копирует используемые hostlist/ipset-файлы и бинарные шаблоны;
- строит `TCP_PORTS`/`UDP_PORTS` для штатного init-скрипта;
- формирует читаемый `REPORT.md` и машинный `report.json`;
- создаёт `web-import/` с конфигом и `.list`-файлами для установки через веб-интерфейс Keenetic без загрузки бинарных `blobs`;
- по желанию сам устанавливает результат через Web API nfqws2, проверяет запись и перезапускает службу;
- перед установкой создаёт локальную резервную копию, а при ошибке выполняет автоматический откат;
- поддерживает точный и гибридный режимы установки;
- сообщает о неоднозначных и неподдерживаемых параметрах.

Штатные скрипты `nfqws2-keenetic` не изменяются, а проверка его конфига не отключается.

## Требования

- Python 3.9 или новее;
- распакованный каталог актуального `zapret-discord-youtube`;
- установленный на роутере актуальный `nfqws2-keenetic`.

Сторонние Python-зависимости не нужны.

## Графический мастер

Самый простой запуск в Windows:

```text
Запустить конвертер.cmd
```

Или из терминала на любой настольной системе с Tk:

```powershell
python -m zapret_keenetic.gui
```

Мастер сам находит рабочие `.bat`-стратегии, предлагает уникальную папку
результата и показывает все основные параметры без необходимости запоминать
ключи командной строки. Подробности: [docs/GUI_RU.md](docs/GUI_RU.md).

## Быстрый запуск

Из корня этого репозитория:

```powershell
py -3 -m zapret_keenetic `
  "C:\Tools\zapret-discord-youtube" `
  "general (ALT11).bat" `
  --output ".\converted\alt11" `
  --target keenetic `
  --interface eth3 `
  --game-filter disabled `
  --archive
```

Для OpenWrt:

```powershell
py -3 -m zapret_keenetic C:\Tools\zapret general.bat `
  -o .\converted\openwrt `
  --target openwrt `
  --interface pppoe-wan
```

Или установите команду локально:

```powershell
py -3 -m pip install -e .
zapret-keenetic --help
```

## Важные параметры

- `--interface` — WAN-интерфейс. На Keenetic часто встречаются `eth3`, `eth2.2` и `ppp0`, но правильное значение нужно проверить на конкретном роутере.
- `--game-filter disabled|all|tcp|udp` — аналог переключателя Game Filter Flowseal. По умолчанию игровые профили отключены и фиктивный порт `12` не попадает в iptables.
- `--ipset-mode loaded` — если `ipset-all.txt` пуст или содержит только отключающую заглушку, берёт наполненный `ipset-all.txt.backup`. `current` всегда оставляет текущий файл.
- `--no-ipv6` — отключает IPv6 в генерируемом конфиге.
- `--strict` — завершает конвертацию ошибкой при любой неоднозначности; выходной каталог может содержать диагностические промежуточные файлы.
- `--archive` — создаёт ZIP, который удобно перенести на роутер.

Выходной каталог должен быть новым или пустым: это защищает существующие результаты от случайной перезаписи.

## Автоматическая установка на Keenetic

В графическом мастере включите **После конвертации установить через Web API
nfqws2**, выберите режим, введите адрес, пользователя и пароль. Пароль действует
только в памяти до завершения операции и затем очищается. Подробная пошаговая
инструкция: [docs/AUTO_INSTALL_RU.md](docs/AUTO_INSTALL_RU.md).

То же самое из CLI:

```powershell
py -3 -m zapret_keenetic `
  "C:\Tools\zapret-discord-youtube" general.bat `
  -o ".\converted\general" `
  --target keenetic --interface eth3 `
  --install --install-mode hybrid `
  --router-url http://192.168.1.1:90/ `
  --check-services
```

Если `--router-password` и переменная `NFQWS2_ROUTER_PASSWORD` не заданы, CLI
запросит пароль без отображения. Установщик сохраняет текущие файлы, создаёт
недостающие `.list`, загружает и читает обратно каждый файл, меняет конфиг,
перезапускает nfqws2 и проверяет статус. При ошибке прежнее состояние
восстанавливается автоматически.

## Ручная установка результата

Подробная процедура с резервным копированием, командами `scp` и отдельными сценариями Keenetic/OpenWrt приведена в [руководстве пользователя](docs/USER_GUIDE_RU.md).

1. Установите `nfqws2-keenetic` по официальной инструкции.
2. Прочитайте сгенерированный `REPORT.md`; исправьте предупреждения и WAN-интерфейс.
3. Сделайте резервную копию текущего `nfqws2.conf`.
4. Скопируйте `nfqws2.conf`, `lists/` и `blobs/` в:
   - Keenetic/Entware: `/opt/etc/nfqws2/`;
   - OpenWrt: `/etc/nfqws2/`.
5. Перезапустите и проверьте службу:

```sh
service nfqws2-keenetic restart
service nfqws2-keenetic status
```

Если появляются ошибки `iptables: No chain/target/match by that name`, сначала проверьте модули Netfilter, WAN-интерфейс, аппаратный offloading и IntelliQOS. Это не ошибка синтаксиса стратегии.

## Ограничения

`winws` работает через WinDivert на Windows, а `nfqws2` — через NFQUEUE/raw sockets на Linux. Поэтому стопроцентная гарантия одинакового результата невозможна даже при эквивалентных стратегиях: отличаются сетевой стек, MTU, offloading, порядок пакетов и DPI провайдера.

У zapret2 нет точного встроенного эквивалента `hostfakesplit altorder=1`. Конвертер применяет обычный `hostfakesplit` и записывает предупреждение. В строгом режиме такой профиль отклоняется. Все неизвестные опции также явно попадают в отчёт, а не исчезают молча.

## Проверка проекта

```powershell
py -3 -m unittest discover -v
```

Для проверки на всех актуальных профилях Flowseal можно последовательно запускать конвертер в отдельные выходные каталоги и просматривать `report.json`.

## Правовые и эксплуатационные замечания

Используйте инструмент только там, где это разрешено законом и правилами сети. Перед изменением роутера сохраняйте рабочий конфиг. Автор конвертера не может гарантировать, что конкретная стратегия подойдёт вашему провайдеру или модели устройства.
