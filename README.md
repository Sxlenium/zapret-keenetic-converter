# Flowseal → nfqws2

**Конвертер стратегий zapret-discord-youtube для Keenetic и OpenWrt.** Выберите `.bat`-профиль Flowseal на компьютере и получите конфигурацию `nfqws2`, списки и отчёт о переносе. Для Windows есть графическое приложение; те же возможности доступны из командной строки.

[Скачать для Windows](../../releases) · [Быстрый старт](#быстрый-старт) · [Возможности](#возможности-040) · [Инструкции](#документация)

> [!IMPORTANT]
> Это независимый конвертер. Он не устанавливает Flowseal на роутер и не входит в состав проектов [Flowseal](https://github.com/flowseal/zapret-discord-youtube) или [nfqws2-keenetic](https://github.com/nfqws/nfqws2-keenetic). Результат зависит от провайдера, версии nfqws2 и настроек сети. Перед установкой сохраните рабочую конфигурацию роутера.

## Быстрый старт

1. Скачайте ZIP со [страницы выпусков](../../releases), распакуйте его и запустите `ZapretKeeneticConverter.exe`. Python для готовой Windows-сборки не нужен.
2. Отдельно распакуйте [zapret-discord-youtube](https://github.com/flowseal/zapret-discord-youtube/releases). На вкладке **Конвертация** выберите его папку, затем рабочую `.bat`-стратегию, например `general (ALT13).bat`.
3. Проверьте **WAN-интерфейс** и параметры Keenetic. Для ручного переноса нажмите **Конвертировать** и сначала прочитайте `REPORT.md` в папке результата.
4. Перенесите файлы [вручную](docs/USER_GUIDE_RU.md#12-копирование-на-keenetic) или через [web-интерфейс](docs/WEB_INTERFACE_RU.md). Для автоматической установки включите её на вкладке **Установка** до нажатия кнопки конвертации; этот способ доступен только для Keenetic.

Порядок первого запуска и установки: [ИНСТРУКЦИЯ.txt](ИНСТРУКЦИЯ.txt). Пароль роутера вводите только в приложении на своём компьютере.

## Возможности 0.4.0

### Перенос актуальных стратегий Flowseal

- **ALT13 и `hostfakesplit altorder=1`.** Конвертер сохраняет порядок отправки сегментов: часть до хоста, fake хоста, часть после хоста, затем настоящий хост. Для этого в конфиг добавляется совместимая Lua-функция; штатные файлы nfqws2 менять не нужно.
- **`multisplit` и `multidisorder`.** Fake-параметры не переносятся на настоящие сегменты. Для старого порядка `multidisorder` используется `multidisorder_legacy`.
- **Несколько профилей и файлов.** Переносятся отдельные правила `winws`, списки доменов и IP, нужные шаблоны и параметры TCP/UDP. Неподдерживаемые или неоднозначные опции отмечаются в отчёте. **Строгий режим** останавливает конвертацию при предупреждении.

### Управление результатом

- **Точный режим установки по умолчанию.** На роутер переносится выбранная стратегия целиком. Гибридный режим остаётся отдельным вариантом.
- **Автоматическая установка на Keenetic.** Приложение сохраняет прежние файлы, загружает результат через Web API nfqws2, проверяет запись, перезапускает службу и при ошибке пытается восстановить резервную копию. Можно установить результат вручную.
- **Комплект для web-импорта.** Папка `web-import/` содержит конфиг и `.list`-файлы для веб-интерфейса. Отдельно создаются `REPORT.md`, `report.json` и, по выбору, ZIP результата.

### Новый интерфейс и эксперименты

- Вкладки **Конвертация**, **Установка**, **Журнал**; сводка результата справа. Дополнительные настройки и **FAQ** раскрываются по запросу.
- В ZIP есть краткая `ИНСТРУКЦИЯ.txt` с порядком первого запуска и установки.
- **TLS fake из текущего ClientHello** — экспериментальный режим, который заменяет TLS fake-шаблоны текущим сообщением соединения. Это меняет стратегию и может увеличить нагрузку на процессор.
- **Лимит fake-повторов** — ограничивает число повторов поддельных пакетов. `0` сохраняет значение исходной стратегии; уменьшение лимита может снизить нагрузку и одновременно ухудшить обход.

Экспериментальные режимы по умолчанию выключены. Они не гарантируют ускорения или работы конкретного сайта.

## Что получится после конвертации

| Файл или папка | Назначение |
| --- | --- |
| `nfqws2.conf` | Конфигурация для nfqws2 |
| `lists/`, `blobs/` | Используемые списки и исходные шаблоны |
| `web-import/` | Конфиг и списки для web-интерфейса Keenetic |
| `REPORT.md`, `report.json` | Предупреждения и подробности переноса |
| ZIP, если включён | Копия комплекта для хранения или передачи |

Каталог результата должен быть новым или пустым: существующие файлы не перезаписываются без вашего выбора.

## Запуск из исходников

Нужны Python 3.9+ с Tk для графического окна и распакованная папка Flowseal. Дополнительные Python-библиотеки для обычного запуска не требуются.

```powershell
py -3 -m zapret_keenetic.gui
```

Для командной строки:

```powershell
py -3 -m zapret_keenetic "C:\Tools\zapret-discord-youtube" "general (ALT13).bat" `
  --output ".\converted\alt13" --target keenetic --interface eth3
```

`eth3` — пример: используйте WAN-интерфейс своей конфигурации. Все аргументы: `py -3 -m zapret_keenetic --help`.
