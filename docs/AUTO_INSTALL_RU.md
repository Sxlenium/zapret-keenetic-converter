# Автоматическая конвертация и установка на Keenetic

Функция выполняет весь путь от выбранного `.bat`-профиля Flowseal до
работающей службы nfqws2. Ручное создание списков во вкладке **Списки** и
вставка большого `nfqws2.conf` не требуются.

## Что должно быть готово

1. На Keenetic установлен и хотя бы один раз запущен `nfqws2-keenetic`.
2. Открывается его web-интерфейс, обычно `http://192.168.1.1:90/`.
3. Имя пользователя и пароль именно web-интерфейса Entware.
4. Распакован каталог `zapret-discord-youtube` с `.bat`, `bin/` и `lists/`.

Сам пакет nfqws2 программа не устанавливает и не обновляет. Она меняет только
пользовательский `nfqws2.conf` и необходимые текстовые `.list`.

## Режимы установки

### Гибридный — рекомендуется для Discord и YouTube

- Discord-специфичные профили берутся из выбранного `.bat` Flowseal;
- YouTube использует штатную адаптивную стратегию текущей версии nfqws2;
- наполненный `ipset-all.txt.backup` подключается автоматически, если основной
  файл пуст или содержит только отключающую заглушку;
- пакетный `nfqws2.conf-opkg` используется как основа и не изменяется.

Это повторяет схему, проверенную с `general.bat`: отдельные правила Discord
имеют приоритет, а YouTube остаётся на адаптивной стратегии роутера.

Гибридный режим требует, чтобы выбранная стратегия содержала распознаваемые
правила Discord. Если их нет, программа остановится до изменения роутера.

### Точный

На роутер устанавливается весь конвертированный профиль Flowseal. Выбирайте его,
если конкретная ALT-стратегия уже проверена у вашего провайдера и должна быть
перенесена без объединения со штатной стратегией nfqws2.

## Установка из графического окна

1. Запустите **`Запустить конвертер.cmd`**.
2. Выберите корневую папку Flowseal.
3. В поле **Стратегия** выберите нужный `.bat`.
4. Проверьте WAN-интерфейс, игровые порты, IPSET, IPv6 и политику Keenetic.
5. В разделе **Автоматическая установка на Keenetic** включите флажок
   **После конвертации установить через Web API nfqws2**.
6. Выберите **Гибридный** или **Точный** режим.
7. Введите адрес. Допустим как `http://192.168.1.1:90/`, так и полный адрес
   `http://192.168.1.1:90/index.php`.
8. Введите пользователя и пароль. Пароль не попадает в результат,
   `deployment.json`, резервную копию или настройки.
9. Оставьте включённой проверку YouTube и Discord, если профиль предназначен
   для этих сервисов.
10. Нажмите **Конвертировать и установить** и подтвердите изменение роутера.

В журнале появятся подключение, путь резервной копии, загрузка каждого списка,
замена конфига, перезапуск и итоговый статус.

## Установка из CLI

При таком запуске пароль запрашивается без отображения:

```powershell
py -3 -m zapret_keenetic `
  "C:\Tools\zapret-discord-youtube-1.10.1" `
  "general.bat" `
  --output ".\converted\general-keenetic" `
  --target keenetic `
  --interface eth3 `
  --ipset-mode loaded `
  --install `
  --install-mode hybrid `
  --router-url "http://192.168.1.1:90/" `
  --router-user root `
  --check-services
```

Для точной установки используйте `--install-mode exact`.

Для автоматизации пароль можно передать через переменную окружения
`NFQWS2_ROUTER_PASSWORD`. Не помещайте файл с паролем в Git и не публикуйте
вывод окружения. Передавать пароль параметром `--router-password` удобнее, но
менее безопасно: значение может остаться в истории команд и списке процессов.

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| `--install` | выключен | автоматически установить результат |
| `--install-mode hybrid` | `hybrid` | Discord Flowseal + адаптивный YouTube |
| `--install-mode exact` | — | установить весь конвертированный профиль |
| `--router-url URL` | `http://192.168.1.1:90/` | адрес Web API nfqws2 |
| `--router-user NAME` | `root` | пользователь Web API |
| `--router-password` | запрос | явно переданный пароль |
| `--router-password-env NAME` | `NFQWS2_ROUTER_PASSWORD` | имя переменной с паролем |
| `--router-timeout SEC` | `60` | сетевой тайм-аут |
| `--backup-dir DIR` | внутри результата | другое место резервных копий |
| `--check-services` | выключен | проверить YouTube и Discord с компьютера |

## Какие файлы загружаются

Программа использует подготовленный каталог `web-import`:

```text
web-import/
├── nfqws2.conf
└── lists/
    ├── list-general.list
    ├── list-google.list
    ├── ipset-all.list
    └── другие списки выбранной стратегии
```

Бинарные fake-пакеты уже встроены в web-конфиг как шестнадцатеричные значения,
поэтому отдельная загрузка `blobs/*.bin` через web-интерфейс не нужна.

В гибридном режиме создаётся `web-import/nfqws2-hybrid.conf` — копия конфига,
фактически отправленного на роутер.

## Резервная копия и откат

Перед первой записью создаётся каталог вида:

```text
<результат>/router-backups/router-backup-20260813-153000/
├── nfqws2.conf
├── manifest.json
└── lists/
```

В копию входят текущий конфиг и все существующие списки, которые будут
заменены. `manifest.json` содержит имена старых и новых файлов, режим и адрес
API, но не пароль.

При ошибке записи, проверки или запуска программа:

1. возвращает содержимое существовавших списков;
2. удаляет списки, созданные этой попыткой;
3. возвращает прежний `nfqws2.conf`;
4. снова перезапускает nfqws2;
5. сохраняет локальную копию для возможного ручного восстановления.

## Проверка после установки

Успешная установка означает, что Web API подтвердил работу службы и процесса
nfqws2. Дополнительная проверка YouTube/Discord выполняется с компьютера и
записывается в `deployment.json` и журнал окна.

Полностью перезапустите Discord и обновите YouTube через `Ctrl+F5`, чтобы старые
TCP/QUIC-соединения не влияли на результат. Отдельно проверьте запуск и
перемотку видео, голосовой канал и демонстрацию экрана.

Если проверка сайта не прошла, но nfqws2 запущен, выбранная стратегия может не
подходить конкретному провайдеру. Попробуйте другой `.bat` или переключитесь
между точным и гибридным режимом.
