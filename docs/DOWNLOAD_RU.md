# Скачивание и первый запуск

## Готовая Windows-сборка

1. Откройте страницу [Releases](../../../releases).
2. В разделе **Assets** скачайте файл с именем вида
   `ZapretKeeneticConverter-v0.4.0rc3-windows-x64.zip`.
3. Распакуйте ZIP в обычную папку. Не запускайте программу прямо из окна архиватора.
4. Прочитайте `ИНСТРУКЦИЯ.txt` и дважды щёлкните `ZapretKeeneticConverter.exe`.
5. Укажите каталог распакованного `zapret-discord-youtube`, выберите `.bat`-профиль
   и параметры конвертации.

В готовой сборке уже находится Python-окружение программы. Устанавливать Python,
пакеты `pip` или сам конвертер в систему не требуется. Исходный каталог
`zapret-discord-youtube` в архив намеренно не включён: пользователь выбирает свою
актуальную копию отдельно.

## Предупреждение Windows SmartScreen

Исполняемый файл пока не подписан платным сертификатом разработчика. Поэтому Windows
может показать окно **Система Windows защитила компьютер**. Сверьте контрольную сумму,
после чего нажмите **Подробнее → Выполнить в любом случае**. Не запускайте файл,
полученный из постороннего источника или с несовпадающей суммой.

## Проверка SHA-256

Рядом с архивом публикуется `SHA256SUMS.txt`. В PowerShell выполните:

```powershell
Get-FileHash .\ZapretKeeneticConverter-v0.4.0rc3-windows-x64.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

Строки SHA-256 должны совпасть полностью.

## Альтернативный запуск из исходников

Если нужна проверяемая исходная версия, скачайте **Source code (zip)** на странице
выпуска, установите Python 3.9 или новее и запустите:

```powershell
py -3 -m zapret_keenetic.gui
```

Для обычного пользователя рекомендуется готовый `windows-x64.zip`.
