# Утверждённое направление интерфейса

Выбор пользователя от 22 сентября 2026: вариант 1 «Утилита» с цветовой палитрой варианта 3 «Рабочая панель».

## Компоновка

- Вкладки «Конвертация», «Установка», «Журнал».
- Основные поля слева; сводка стратегии, папка результата и выходные файлы справа.
- Дополнительные и экспериментальные параметры раскрываются по запросу.
- По уточнению пользователя расположение переключателей сохраняется; на вкладке «Конвертация» доступна раскрываемая справка «FAQ» под разделом «Дополнительные параметры» по IPv6, исключению политики, строгому режиму, ZIP, TLS clone и лимиту fake-повторов.
- Статус и основная кнопка конвертации внизу окна.
- Параметры подключения показываются при включении автоматической установки.
- Сдержанное настольное оформление, Segoe UI, компактные элементы управления.

## Состояние

Направление утверждено и перенесено в GUI версии 0.4.0rc2. Это решение не подтверждает испытания конвертера на роутере.

Исходный макет: `converter-designs.html`, первый вариант.
