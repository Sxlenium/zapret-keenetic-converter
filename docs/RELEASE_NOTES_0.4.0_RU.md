# Zapret Keenetic Converter 0.4.0

Готовая Windows-сборка конвертирует `.bat`-стратегии Flowseal в комплект для
nfqws2 на Keenetic. Распакуйте ZIP и начните с `ИНСТРУКЦИЯ.txt`; Python для
запуска EXE не нужен. Сам Flowseal скачивается отдельно.

В версии 0.4.0:

- ALT13 с `hostfakesplit altorder=1` переносится с сохранением порядка сегментов;
- правила `multisplit` и `multidisorder` сохраняют разделение настоящих и fake-пакетов;
- результат включает `nfqws2.conf`, списки, `web-import/` и отчёт `REPORT.md`;
- доступны ручной перенос и автоматическая установка через Web API nfqws2 с
  резервной копией и попыткой отката при ошибке;
- интерфейс разделён на вкладки «Конвертация», «Установка» и «Журнал», а редкие
  параметры объяснены в FAQ;
- TLS fake из текущего ClientHello и лимит fake-повторов доступны как
  выключенные по умолчанию эксперименты.

Пользователь подтвердил работу ALT13 на Keenetic Giga KN-1012 с KeeneticOS 5.1.3,
nfqws2-keenetic 1.2.8 и web 3.0.23. Автоматическая сборка проверяет тесты,
запуск Windows EXE и контрольные суммы. Работа других стратегий и конфигураций
зависит от сети и проверяется отдельно.

Для скачивания используйте `ZapretKeeneticConverter-v0.4.0-windows-x64.zip`.
Контрольная сумма архива и EXE находится в `SHA256SUMS.txt`.
